0.7 开发分支的[可靠 Redis 确认预算](redis-durability-budget.md)将入队与后台 Outbox 的 AOF/I/O 等待分别配置，并让排队、重连、写入、确认消费原总预算。默认 AOF 仍为 2 秒，可靠 ACK 不降级；新连接不能确认旧连接的写入。新增阶段耗时、超时与队列等待观测，修改版需要重新构建、重启及独立长稳。
