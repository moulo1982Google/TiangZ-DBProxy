# A12：Outbox 同键路由组合与锁定前缀

RunId `a12_20260929a`，三个新库 `_matrix/_prefix/_heads`，三项真实 PG 测试全部通过。

新增矩阵为 2 个 publisher × 2 个 destination，四组共用相同 partition key，每组一条队首、一条后继。轮流阻塞四组中的每一组，分别注入退避、有效租约、行锁和死信，共 16 个场景、128 条事件。

每场景先保留其他三组的有效租约不确认，要求继续领取时不重复返回这些事件、不越过任一队首。核对每条返回消息的 publisher、destination、event_id，再确认队首、领取并确认后继。最后修复阻塞组，要求该组按队首/后继顺序恢复；两个 publisher 均再无可领取事件。全程未调用外部 MQ。

| 测试 | 验证范围 | 耗时 |
| --- | --- | ---: |
| 新路由矩阵 | 16 个场景全部通过，同键不同路由相互独立 | 8.14 秒 |
| 锁定前缀重跑 | 31/32/33/40 前缀，8 路并发领取，连续确认无重复且顺序正确 | 10.05 秒 |
| 阻塞队首重跑 | 四类队首阻塞，其他 key 可推进，同组后继不能越过 | 3.39 秒 |

这是功能矩阵，不是 P07 的完整分布、吞吐或长期公平性测量。16 个路由场景与四个前缀边界分别验证，没有声称两者做了完整笛卡尔积压力测试。
